## Body

The 30-Day Set is designed around one idea: a fresh French manicure every morning, for thirty days.

**Inside the box:**

- 30 individually sealed daily French manicure sets
- Each set includes 10 nails (sizes 0–9) in the Daily French shape
- Adhesive tabs for every set — single-use, already matched
- Prep pads for every set
- A removal guide

**The nail:**

Medium-short softly rounded almond shape. Matte milky base. Softly glossy French tip. A slightly shorter thumb nail to proportion correctly for real hands doing real things.

**The format:**

Every single set is sealed individually. You open one each morning, apply it, wear it all day, remove it at night, and the next morning you open a new one. Nothing is reused. Nothing carries over.

**The result:**

A fresh French manicure every morning, for thirty days straight. Clean, finished hands without protecting a two-week manicure or living with bare nails.
